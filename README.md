# Job Match AI

תוסף לכרום שאוסף משרות הייטק פתוחות מלוחות משרות ציבוריים של חברות (בעיקר ישראליות), מדרג אותן מול כמה גרסאות של קורות החיים שלך בעזרת Gemini, ואומר לך לאיזו משרה כדאי להגיש, עם איזו גרסה, ומה לשפר בקורות החיים בשבילה.

הכול רץ בדפדפן שלך. אין שרת, ואין חשבון.

האפיון המלא: [SPEC.md](SPEC.md).

## מה התוסף עושה

- **איסוף משרות** מ-Greenhouse, ‏Lever, ‏SmartRecruiters ו-Comeet, דרך ה-API הציבורי של כל לוח. לא סורק את LinkedIn, ‏AllJobs או דרושים.
- **סינון בלי AI:** לפי מיקום, תחום (לפי התחומים שבחרת לכל גרסת קורות חיים), שנות ניסיון ותפקידים בכירים מדי.
- **דירוג עם Gemini:** ציון 0–100, הגרסה המומלצת, הסבר לציון, ו-3–5 טיפים ספציפיים למשרה. ההוראה ל-Gemini היא לא להציע להוסיף כישורים שאין לך.
- **ניהול משרות:** "הגשתי" (ואיזו גרסה נשלחה), "שמירה להמשך", "לא רלוונטי", מאגר משרות עם סינון וחיפוש, וסטטיסטיקה.
- **ריצה יומית אוטומטית** בשעה שבחרת, עם התראה ומספר על אייקון התוסף. אחרי הריצה הראשונה מטפל רק במשרות חדשות.
- **מילוי טפסי הגשה:** "מלאי טופס" פותח את טופס ההגשה, והתוסף ממלא שם, מייל, טלפון ולינקדאין ומצרף את קורות החיים המומלצים. **התוסף אף פעם לא לוחץ על "שליחה".**
- **אנשי קשר והפניות:** כשיש לך קשר בחברה, "בקשת הפניה במייל" כותב טיוטה בעברית ופותח אותה ב-Gmail.

## דרישות

- Chrome בגרסה 140 ומעלה.
- [Node.js](https://nodejs.org) (גרסת LTS) ו-[Git](https://git-scm.com), כדי לבנות את התוסף.
- מפתח Gemini API (חינמי, הסבר בהמשך).

## התקנה

```bash
git clone https://github.com/yael6268/job-match-ai.git
cd job-match-ai
npm install
npm run build
```

התוסף נבנה לתיקייה `.output/chrome-mv3`. טעינה בכרום:

1. לפתוח `chrome://extensions` ולהפעיל **מצב מפתח** (Developer mode) בפינה העליונה.
2. ללחוץ **טעינת תוסף לא ארוז** (Load unpacked) ולבחור את התיקייה `.output/chrome-mv3` עצמה. בתוכה צריכים להופיע `manifest.json`, ‏`background.js` ו-`sidepanel.html`.
3. לוודא שהמתג בכרטיס התוסף דלוק, ולהצמיד את האייקון (סמל הפאזל בסרגל הכלים ← נעץ).
4. ללחוץ על האייקון. החלונית נפתחת בצד.

### עדכון לגרסה חדשה

```bash
git pull
npm install
npm run build
```

ואז ב-`chrome://extensions` ללחוץ ⟳ בכרטיס של התוסף, ולסגור ולפתוח את החלונית. **בלי ⟳ הרקע של התוסף ממשיך להריץ את הגרסה הקודמת.**

## הגדרה ראשונה

### 1. מפתח Gemini

1. להיכנס ל-[Google AI Studio](https://aistudio.google.com/app/apikey) עם חשבון Google וליצור מפתח API.
2. בתוסף: ⚙️ הגדרות ← Gemini, להדביק את המפתח, ללחוץ **טעינת מודלים** ולבחור מודל Flash.
3. ללחוץ **בדיקת מפתח**. אמור להופיע "המפתח תקין".

כדאי לבדוק ב-AI Studio כמה קריאות ביום המכסה החינמית מאפשרת, ולהתאים את "מגבלת קריאות AI ליום" בהגדרות (ברירת מחדל: 200).

### 2. קורות חיים

ב-📄 קורות חיים להעלות קובץ PDF או DOCX לכל גרסה, לתת שם (למשל "Full Stack ‎.NET") ו**לסמן תחומים**. התחומים קובעים אילו משרות עוברות את הסינון: משרה עוברת אם הכותרת שלה מתאימה לתחום של לפחות גרסה אחת. אפשר לראות את הטקסט שחולץ ואת הגרסה המצונזרת שנשלחת ל-AI.

> משרה שכבר נסוננה לא נבדקת שוב. אם מוסיפים תחום, הוא חל על משרות חדשות.

### 3. פרטי הגשה

ב-📝 פרטי הגשה למלא שם, מייל, טלפון ולינקדאין. מכאן ממולאים טפסי ההגשה וטיוטות ההפניה.

### 4. חברות

ב-⚙️ הגדרות ← חברות:

- **החברות המומלצות:** כפתור אחד מוסיף רשימה של חברות עם משרות פיתוח בישראל שנבדקו מול ה-API.
- **הוספה ידנית:** "+ הוספת חברה", בחירת מקור, ולחיצה על **בדיקה** לפני השמירה. מזהה הלוח לפי מקור:

| מקור | איפה המזהה | דוגמה |
|---|---|---|
| Greenhouse | בכתובת `boards.greenhouse.io/‹מזהה›` או `job-boards.greenhouse.io/‹מזהה›` | `taboola` |
| Lever | בכתובת `jobs.lever.co/‹מזהה›` | `walkme` |
| SmartRecruiters | בכתובת `jobs.smartrecruiters.com/‹מזהה›` (רגיש לאותיות גדולות). שדה "מדינה" מסנן לפי מדינה, `il` כברירת מחדל | `CheckPointSoftwareTechnologies2` |
| Comeet | להדביק את הקישור לעמוד המשרות (`www.comeet.com/jobs/‹חברה›/‹מזהה›`) וללחוץ **שליפת פרטים**. המזהה והטוקן מתמלאים לבד | `49.004` |

הרבה חברות מציגות את המשרות באתר שלהן. אם רואים שם `gh_jid=` בכתובת, החברה ב-Greenhouse; `jobs.lever.co` זה Lever; `comeet` זה Comeet.

## שימוש יומיומי

1. ✨ ההתאמות היומיות ← **לחיפוש של היום**. ריצה ראשונה עם הרבה חברות לוקחת כמה דקות, בעיקר בגלל ההשהיה בין קריאות ה-AI.
2. בכל כרטיס: הציון, הגרסה המומלצת, "למה הציון?", וטיפים.
3. **מלאי טופס:** פותח את טופס ההגשה וממלא אותו. לבדוק, להשלים את מה שחסר (שאלות פתוחות, רשימות בחירה), ולשלוח בעצמך. בחלונית הצפה אפשר ללחוץ **סמני כהוגשה**.
4. **הגשתי / שמירה להמשך / לא רלוונטי:** המשרה יוצאת מהרשימה ונשמרת ב-💼 מאגר המשרות.
5. הריצה היומית קורית לבד בשעה שב"שעת ריצה יומית". אם המחשב היה כבוי יותר מיממה, ריצת השלמה מתחילה כשכרום נפתח.

**גיבוי:** ⚙️ הגדרות ← גיבוי ונתונים ← **ייצוא גיבוי**. הקובץ כולל הכול חוץ ממפתח ה-API. כדאי לגבות לפני הסרת התוסף, כי הסרה מוחקת את כל הנתונים.

## פרטיות

- **כל הנתונים נשמרים רק בדפדפן שלך** (IndexedDB ו-`chrome.storage.local`): קורות החיים, המשרות, ההגשות, אנשי הקשר והמפתח. שום דבר לא נשלח לשרת של התוסף, כי אין כזה.
- **מה יוצא מהמחשב, ולאן:**
  - בקשות קריאה בלבד ל-API הציבורי של לוחות המשרות (Greenhouse, ‏Lever, ‏SmartRecruiters, ‏Comeet).
  - ל-Gemini (Google) נשלחים **רק** הטקסט המצונזר של קורות החיים, בלי טלפון, מייל וכתובת, ותיאורי משרות ציבוריים. לטיוטות הפניה נשלחים גם שם איש הקשר והשם הפרטי שלך.
- **שימו לב:** במסלול החינמי של Gemini API, Google עשויה להשתמש בתוכן שנשלח אליה כדי לשפר את המוצרים שלה. מי שזה מפריע לו יכול להשתמש במפתח של מסלול בתשלום.
- מפתח ה-API נשלח רק בכותרת `x-goog-api-key` ל-`generativelanguage.googleapis.com`, לא נרשם בלוגים, לא מופיע בכתובות ולא נכלל בקובץ הגיבוי.
- התוסף מיועד לשימוש אישי. פרסום בחנות של Chrome ידרוש להעביר את קריאות ה-AI לשרת קטן, כדי שהמפתח לא יהיה בתוך התוסף.

## פתרון בעיות

| מה רואים | מה לעשות |
|---|---|
| "Manifest file is missing or unreadable" | נבחרה תיקייה לא נכונה. לבחור את `.output/chrome-mv3` עצמה. |
| "רקע התוסף לא מעודכן" / כפתור חדש לא עושה כלום | ללחוץ ⟳ על התוסף ב-`chrome://extensions` ולפתוח מחדש את החלונית. |
| "עברו סינון: 0" | לבדוק את התחומים של קורות החיים ואת רשימת המיקומים בהגדרות, ושיש חברות עם משרות מתאימות. |
| "חרגת ממכסת הקריאות" (429) | המכסה של Gemini נגמרה. המשרות שנשארו ינותחו בריצה הבאה. |
| Comeet מחזיר 404 או לא נטען | ברשתות מסוננות (למשל NetFree) Comeet עלול להיחסם. אפשר להזין מזהה וטוקן ידנית: בעמוד הקריירה, Ctrl+U, לחפש `company_uid` ולהעתיק את ה-`token` שאחריו. |
| הטופס לא מתמלא | לוודא שפרטי ההגשה מלאים ושהתוסף רוענן. רשימות בחירה (מדינה, עיר) ושאלות פתוחות ממלאים ידנית. טפסים בתוך iframe באתר של החברה לא נתמכים; "מלאי טופס" פותח את הטופס ישירות. |

## פיתוח

```bash
npm run dev         # WXT dev mode
npm run build       # -> .output/chrome-mv3
npm test            # vitest (no network)
npm run test:live   # real job-board APIs (network)
npm run typecheck
```

- TypeScript במצב strict, ‏React 18, ‏WXT (Manifest V3), ‏Dexie, ‏zod, ‏pdfjs-dist, ‏mammoth.
- הקוד, השמות וההערות באנגלית; כל הטקסט בממשק בעברית ומימין לשמאל.
- מבנה התיקיות והחלטות התכנון מתוארים ב-[SPEC.md](SPEC.md).
- הבדיקות לא פונות לרשת אמיתית או ל-Gemini. קובצי הדוגמה ב-`tests/fixtures` הם תשובות API אמיתיות מקוצרות, בלי מידע אישי, או נתונים בדויים.
- האייקונים נוצרים עם `node scripts/make-icons.mjs`.
